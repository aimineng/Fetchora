Fetchora 扩展设置

这些选项保存在浏览器账号中，并立即生效。

连接

桌面程序端口
需与「设置 → 浏览器集成 → 监听端口」保持一致，默认 8899。
使用 WebSocket 实时通道
关闭后仅使用 HTTP 接口（兼容旧版本桌面程序）。
连接状态
正在检测…

自动接管

接管浏览器下载
浏览器发起下载时自动转发给 aria2，并取消浏览器自身的下载。
最小文件体积（KB）
小于该体积的下载留给浏览器；0 表示全部接管。
忽略的文件扩展名
逗号分隔，例如 pdf,html,txt
忽略的站点
逗号分隔的主机名片段，例如 drive.google.com
发送 Referer
把来源页面一并传给 aria2，可解决部分站点的防盗链。

通知

下载完成时通知
任务完成时在浏览器中弹出通知。

使用说明

  1. 启动 Fetchora 桌面程序。
  2. 在「设置 → 浏览器集成」中确认已开启浏览器集成，并记下监听端口。
  3. 把此处端口改成一致的值，点击「测试连接」应显示已连接。
  4. 右键菜单还提供「用 Fetchora 下载此链接 / 媒体 / 页面」等快捷操作。
